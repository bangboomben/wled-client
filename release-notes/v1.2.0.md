### What's new
- **Automatic updates.** The app now checks this page for new releases, downloads them in the background and installs them on the next restart — or right away via *Restart now*. Can be turned off in *App settings*.
- Demo GIF in the README.

### Install / update
Download **WLED-Client-Setup-1.2.0.exe** below and run it — per-user install, no admin rights. Installing over an earlier version keeps your devices and settings.
**Coming from 1.0 or 1.1?** Install this version once by hand; from here on updates arrive automatically.

The installer is not code-signed yet: if SmartScreen warns, choose **More info → Run anyway**.

Interface in English and German (follows your Windows language). Tested with WLED 16.0.1 on ESP32.
