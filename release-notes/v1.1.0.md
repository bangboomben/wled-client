### What's new
- **English interface.** The whole app — windows, dialogs, tray menu, messages — is now available in **English and German**. It follows your Windows language and can be switched in *App settings → Language*.
- Terminology matches the English WLED web UI (Segments, Grouping, Spacing, Nightlight, Quick load …).
- The installer is bilingual as well.

### Install / update
Download **WLED-Client-Setup-1.1.0.exe** below and run it — per-user install, no admin rights. Installing over 1.0.0 keeps your devices and settings.
The installer is not code-signed yet: if SmartScreen warns, choose **More info → Run anyway**.

Tested with WLED 16.0.1 on ESP32.
