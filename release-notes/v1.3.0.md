### What's new
- **Device discovery via mDNS.** The app now finds WLED devices the way WLED announces itself: mDNS and the WLED node list. It works in networks of any size and no longer probes every address. The address scan is still there, but only when you ask for it: *Add device → Device missing? Scan an address range*. It now uses your real netmask.
- **Devices with a new IP address are found again.** If a saved device is offline and turns up at a new address, the app switches to that address.
- **Safer device pages.** The device's own web pages open in a separate, locked-down session. They can't start other programs through link protocols or navigate away on their own, and links open in your browser only when you click them.
- **More robust against unexpected data.** A broken `presets.json`, oversized responses or odd values from a device no longer break the window. Save, delete and reboot now report an error when the device doesn't confirm them.
- **Smaller fixes:**
  - Changing a device's address while it reconnects no longer leaves a stray connection behind.
  - Firmware without effect metadata is no longer asked for it again and again.
  - A damaged settings file no longer stops the app from starting.

### Install / update
Running 1.2.0? The update arrives automatically. Otherwise, download **WLED-Client-Setup-1.3.0.exe** below and run it. It installs per user and needs no admin rights. Installing over an earlier version keeps your devices and settings.

The installer is not code-signed yet. If SmartScreen warns, choose **More info → Run anyway**.
